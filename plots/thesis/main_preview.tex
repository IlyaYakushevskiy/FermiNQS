\begin{abstract}

In the last few years, neural network wave functions have proven effective in describing many-body quantum systems. In particular, architectures such as FermiNet, PauliNet, and PsiFormer
have been successful in tackling systems of interacting electrons in quantum chemistry. However,
these all rely on representing antisymmetric fermion wave functions as determinants, whose evaluation may be prohibitively expensive for large systems.
A recently proposed alternative approach implements fermionic antisymmetry using a permutation symmetric neural network extended with a predefined antisymmetric function inspired by fractional quantum Hall states. In principle, such a neural network may be computationally more efficient than the standard approach.

\end{abstract}

\section{Introduction}

In theoretical condensed matter in order to describe properties of material it is usually sufficient to describe the ground state of the many body system. However, it had always been a hard task to solve, which was mainly accomplished by various variational methods. It is becoming particularly hard to solve Quantum Many Body system, which include non-trivial strongly correlated interactions. 
Recently, relatively new approaches to model Wavefunction had emerged, such as Neural Quantum States (NQS)\cite{carleo_solving_2017}. Using it as the ansatz with the finite basis set in Variational Monte Carlo (VMC) techniques had improved the accuracy of the method significantly. 



While the computational cost of a bosonic ansatz can scale favorably, encoding the required spin statistics for fermions introduces a major structural challenge. For bosons, one can achieve permutation invariance through simple symmetric pooling, but fermions require a totally antisymmetric wavefunction to satisfy the Pauli Exclusion Principle. This necessitates the use of the Slater Determinant, using LU-decomposition it can be calculated in $O(n^3)$, which can be a bottleneck for training systems with large number of fermions. 

Different methods were proposed over the year to approach it, such calculating Slater Determinant, Pfafian ,  as backflow transformations initialy proposed by R.Feynman  \cite{feynman_energy_nodate} , ...  and later realised as neural backflow \cite{pfau_ab_2020}

Generally the driver defines training loop which generates samples with Monte Carlo, evaluates the local energies $E_{loc}$ ,  calculates the gradients and updates parameters of $VMC_\theta$.

\subsection{Neural Network Ansatz for Fermions}
\label{sec:nn_ansatz}

While for bosons -- for fermions Slater scales as ... 

for fermions efficiently representing antisymmetric states remains a major challenge. The standard aproach for fermions The standard approach is to expand $\Psi$ in terms of Slater determinants constructed from a single-particle basis set $ /phi (r), ..., φ_L(r).$
The problem with Slater determinant, is that it scales exponentially with number of N particles. From perspective of computational cost, it translates to the $O(n^3)$ complexity, when solving the Slater determinant with LU decomposition. The main goal of this thesis is to verify Ansatz alternative to the Slater determinant, which could bring down the computational cost to $O(n^2)$, thus beeing more efficient representation for fermionic wavefunctions. Such Ansatz was first proposed to use a symmetrical part and antisymmetric part as arguments to neural network. \cite{fu_minimal_2025}

\begin{equation}
\psi(r_1 ,..., r_n) = \Psi( r_1, ...,r_n,  \eta(r_1 ,..., r_n  ))
\end{equation}


Where $\Psi$ is implemented as Neural Network. While we know how to make symmetrized Ansatz for bosonic case \ref{tab:deepsets} the challenge is to construct so called \textit{signature encoder}:

\begin{equation}
    \eta = \prod_{1 \le j < i \le N} (x_i - x_j)
\end{equation}

Which can be extended to 2 dimmensions using the complex coordinates. 

\begin{equation}
    \eta = \eta_1 + i \eta_2 = \prod_{1 \le j < i \le N} (z_i - z_j)
\end{equation}


Later in this work we use regularised version of the $\eta$ for stabitily at the nodes when

$ |z_i - z_j| \rightarrow 0 $

\begin{equation}
\title{eq:eta}
\eta = \prod_{1 \le j < i \le N} \frac{z_i - z_j}{\sqrt{|z_i - z_j|^2 + a^2}}
\end{equation}

We going to start with a simplest system, 4 spinless fermions in Quantum Harmonic oscilator potential with the following Hamiltonian to test our ansatz : 

\begin{equation}
\hat{H}_0
=
\sum_{i=1}^{4}
\left[
    -\frac{\hbar^{2}}{2m}\nabla_i^{2}
    + \frac{1}{2} m \omega^{2} \mathbf r_i^{2}
\right]
\end{equation}

Let us look first at 2D case, we define $ m  \omega^2 = 1  $ , so we can find analytic ground state as $ \hbar \omega ( n + 1 )  $. The problem with training the network for 4 fermion arises from the three-degenerate ground state. 


From analysis of possible $n = n_x + n_y$ single particle wavefunction we can see closest states to groundstate will be : 




(n = 0) : (0,0)

(n = 1) : (0,1), (1,0)

(n = 2): (0,2), (2,0), (1,1) 

(n = 3) : (1,2), (2,1), (3,0), (0,3)

 
So the true Ground state would be of the form: 

\begin{equation}
\Psi_{\mathrm{GS}}
=
c_1\,\Psi_{2,0}
+
c_2\,\Psi_{1,1}
+
c_3\,\Psi_{0,2}
\end{equation}

and the Energy of this system would be : 
\begin{equation}
    E = \hbar \omega ( n_x + n_y + \frac{1}{2} + \frac{1}{2}) =  \hbar \omega  (( 0 + 0 + 1 ) + ( 0 + 1 + 1  )  +  ( 1 + 0 + 1  ) + ( 0 + 2 + 1  )) =  \hbar \omega 8
\end{equation}


From our energy convergece graph \ref{fig:n4energy} we see that all configurations are heavily biased to the state with E = 10 , which, as testing with different N confirms is always the exact Laughlin state.

\subsection{Results with radial symmetry assumption}

Where finally achieved first success was in introducing the radial symmetry for 2D QHO, this is a special case which works when the ground state is  radially symmetrical, this means we must have spherical potential as well as GS must be non-degenerate. 

We thus can work with systems of 3,6,10,... particles. Later we will test it on quantum dot system, where we encode the Coulomb interaction \ref{sec:q_dot} 

For such system we know for fact that $ [\hat{H}, \hat{L_z}] = 0$, meaning that Eigen energies of the Hamiltonian are also eigenenergies of $\hat{L_z}$ operator. 

We thus need a projection of our neural network onto $\hat{L_z}$. The way we achieve it is to apply rotation matrix k times with angles $ \theta = \frac{k}{2 \Pi}$  to the coordinates input into symmetrical part (Nerual Network) and then average it out. We must note that this increases the computational cost by factor of k. Hence the cost of ansatz is $O(k \cdot n^2 )$ compared to $O( n^3)$ in case of the Slater Determinant ansatz. The scaling of error with k and N is yet to be studied.
